# **BUGSY**
Reinforcement Learning-Based Automated Game Testing
Explore autonomously. Detect anomalies. Investigate game bugs.

BUGSY is a Unity-based automated game-testing framework that combines Proximal Policy Optimization (PPO) driven novelty exploration with physics-based anomaly detection.

The framework enables an autonomous agent to explore game environments while an independent anomaly detection module monitors physical behaviour for potential inconsistencies. Controlled fault injection and structured event logging support the evaluation of detected anomalies.
